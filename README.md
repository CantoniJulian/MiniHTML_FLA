## FORMAL AND AUTOMATA MINI-HTML PROJECT

	A simple automata for recognizing some simple html files and their structure.

# Description

 The software examines every character tracking proper closure of every HTML tag following a specific Grammar that evokes html file behaviour. 
 Then, it determines whether the string given belongs to the language generated by the Grammar.

# Grammar

Such context-free Gramar is represented in Formal Language and Automata notation by:

$$S \rightarrow S\Sigma_t \mid \langle\Sigma_i\rangle S \langle/\Sigma_i\rangle \mid \lambda$$

$$\text{where}\quad \Sigma_i \in \{b, p, i\} \quad \text{and} \quad \Sigma_t \in \{a, \dots, z\}$$
